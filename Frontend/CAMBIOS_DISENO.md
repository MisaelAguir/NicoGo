# Actualizacion visual NicoGo AI

- Identidad visual actualizada de NicaGo a NicoGo.
- Logo y mascota integrados en assets locales.
- Paleta basada en Figma: verde, turquesa, naranja y superficies blancas.
- Header simplificado con marca, notificaciones y configuracion.
- Navegacion inferior con Inicio, Mapa, IA, Favoritos y Perfil.
- Splash, login y home redisenados.
- Mapa reemplazado por un mapa OpenStreetMap interactivo embebido, con buscador, filtros y geolocalizacion del dispositivo preparada.
- Estilos globales adaptados al lenguaje visual del prototipo.

## Ejecutar

```powershell
npm install
npm run dev
```

`npm install` instalara tambien los tipos de React agregados a devDependencies para corregir los errores JSX de TypeScript.
