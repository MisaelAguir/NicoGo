# NicoGo AI - Frontend Movil

Proyecto React + TypeScript + Vite + Capacitor para el prototipo movil de NicoGo AI.

## Requisitos

- Node.js 22 LTS
- Visual Studio Code
- Android Studio solo si se desea ejecutar en Android

## Ejecutar en navegador

```powershell
cd movil
npm install
npm run dev
```

Abrir:

```text
http://localhost:5173
```

## Compilar

```powershell
npm run build
```

## Ejecutar con Capacitor Android

```powershell
npm run cap:android
```

## Pantallas incluidas

- Splash / bienvenida
- Login
- Seleccion de tipo de usuario
- Registro turista
- Registro negocio / lugar turistico
- Onboarding de preferencias
- Home turistico
- Mapa inteligente con filtros superiores
- Filtros avanzados
- Detalle de lugar
- Recomendaciones IA
- Asistente IA
- Itinerario
- Seguridad
- Comunidad
- Perfil inteligente
- Sincronizacion offline
